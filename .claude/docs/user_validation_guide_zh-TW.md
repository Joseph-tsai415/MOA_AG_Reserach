# 使用者驗證指南 —— 領域專家如何判斷這個研究 agent 的答案好不好

> **對象：** 出題的實驗端研究者、專案負責人（不需要熟悉 pipeline 內部）
> **用途：** 拿到 agent 的回答後，**10 分鐘內**判斷「這個答案能不能拿來做決定」
> **來源：** 2026-08-26 孟青／彥安／Joseph 討論逐字稿 + `.claude/docs/agent_evaluation_zh-TW.md`
> **撰寫日期：** 2026-08-27 · 隨需查閱文件（不自動載入）
> **兩份文件的分工：** 本文＝**使用者版**（怎麼驗收一個答案）· `agent_evaluation_zh-TW.md`＝**評測者版**（怎麼量整套系統的準確度／穩定性／安全性）。本文的每張表都可以直接回填到評測版的題庫裡。

## 0. 這份文件在回答哪一個問題

會議上 Joseph 問了一句話，那就是這份文件存在的理由：

> 「假如說你接下來還有 10 個問題，那我們都要怎麼去判斷說這個 agent 回答是好還是不好？」

孟青的回答是：**「那個就很難。」**

**她是對的，而且原因很具體。** 她之所以判斷得出第一題答得好，是因為那一題她自己讀過文獻、也親手做過實驗 ——
那不是在「評估 agent」，那是「她心裡本來就有答案」。她自己補的那句話更重要：
「其實不應該說是標準答案，應該是我個人的見解。」

標準答案是稀缺資源，不可能每一題都有。所以這份文件**不去回答「這個答案對不對」**，
而是把問題換成三個**每一題都答得出來**的問題：

1. 這是**哪一型**的題目？（你手上有沒有可對照的東西）
2. 這一型**該做到**的事，它有沒有做到？
3. 它沒做到的地方，是**「文獻上本來就沒有」**、**「它沒想到要往那邊找」**，還是**「它自己編的」**？

第 3 點是全文重心。**漏掉一件事，代價是再查一次文獻；編造一件事，代價是白做一個實驗。**
這兩者永遠不可以放進同一個分數裡（§4）。

## 1. 出題前：3 分鐘，決定這一題的分數上限

答案的品質上限由**題目**決定，不是由 agent 決定。這三分鐘比事後爭論值錢。

### 1.1 先把題目歸類 —— T1／T2／T3

這三型正是會議上從孟青那三個問題歸納出來的（Joseph：「我覺得問問題有分三大類」）：

| 型 | 你手上有什麼 | 會議中的例子 | **可以**評什麼 | **不可以**評什麼 |
|---|---|---|---|---|
| **T1** 你已經知道答案 | 你讀過文獻、也做過實驗 | Q1 腸道免疫細胞分離（酵素 × 表位） | 命中率、**捏造率**、有沒有把「未報導」寫成「未報導」 | — |
| **T2** 你有方向性預期，實驗還在跑 | 預期方向，尚未揭盲 | Q2 小腸延長，對照已發表模型 | **預先登錄過的**方向命中、區間覆蓋（事後才計分） | **現在**的絕對正確性 |
| **T3** 根本還沒有答案 | 只有假說 | Q3 皮膚→腸道機轉、外泌體 cargo | 可追溯性、可否證性、安全性覆蓋、**決策實用性** | **正確性** |

> **鐵則：T3 的答案不可以打「正確性」的分數。** 沒有東西可對照，那個分數實際上是
> 「聽起來合不合理」的分數 —— 而優化「聽起來合理」，正是製造出一台自信滿滿的幻覺機器的方法。

### 1.2 填「方法揭露區塊」—— 這是這次會議最重要的一項發現

孟青整場講得最深的一段：**產生資料的方法，決定了答案的偏差**。三個她親身踩過的例子：

- 皮膚 RNase 極多，酵素分離細胞時會瘋狂降解 RNA → 她的實驗室因此**放棄 dissociation，改做 spatial transcriptome**（不分離細胞，整塊組織直接上載玻片測序）。
- 沒有任何一種酵素能完整保留腸道所有細胞型別 → **你想看哪一群免疫細胞，決定你選哪一種酵素**；選錯，population 比例的結論就是假的（表皮細胞大量死亡卻沒被算進 population，比例就偏了）。
- RNA quality（RIN）不過關 → 用她的話說：「全部的 data 就是破陷。」

她自己用 AI 的習慣就是預先講清楚：「我要有這些 clean up 的步驟，就指定，因為有些 paper 可能會用不同的 clean up 步驟。」

**所以：把方法寫進題目，而不是只丟結果資料。** 沒寫，agent 只能給你一個「平均意義下」的答案，
而你事後說它「沒考慮到我的 protocol」，那是題目的問題，不是它的問題。

```
【方法揭露區塊 —— 每一題都貼上】
資料型別：        （bulk RNA-seq / scRNA-seq / spatial / Mass spec / qPCR / 只有文獻）
平台與版本：
組織取得與解離：  （酵素種類與濃度 / EDTA-DTT / 機械 / 不解離—spatial）
QC 門檻：         （RIN = ? · mito% · doublet 處理 · 活細胞比例 · 定量下限）
已知偏差：        （你自己知道這個方法會低估／破壞哪些族群或哪些表位）
沒有的資料：      （明講：這批沒有 CMC / 沒有批次資訊 / 供應商不給）
```

> **拿不到資料時怎麼辦（彥安的外泌體情境）。** 供應商「不敢給那麼細」是常態。
> 這時候**不要**讓 agent 用假設把洞補起來。正確的用法是把缺料本身變成題目：
> 「以下是我能拿到的資料。請列出：(a) 在缺少 RIN／分離方法／MISEV 鑑定的前提下，
> 哪些結論**現在就不成立**；(b) 一份要向供應商索取的最小資料清單，按對結論的影響排序。」
> 一份好的回答會告訴你**該去要什麼**；一份壞的回答會直接分析下去。

### 1.3 填「模型／材料揭露區塊」

Q2 那次最大的失分，起點就在這裡（見 §2 L2-a 的相鄰模型檢查）：

```
【模型／材料揭露區塊】
基因型與組織限定：（例：skin-specific Regnase-1 (Zc3h12a) KO —— 腸道不缺失）
品系 / 年齡 / 性別 / 同窩對照：
觀察到的表型與量級：（例：小腸 +5~10 cm；大腸 ±1~2 cm，個體間變異）
量測條件：        （新鮮 vs 固定、張力、切片方向、n）
外泌體／製劑類：  （來源細胞、分離法、批次、cargo 是自己測的還是文獻拼的）
```

> 彥安在會議中說得很清楚：「裡面定序的結果全部都不是我們做的，是在好幾篇論文裡面看到有什麼關聯，
> 把它拼在一起的。」—— **這件事必須寫在題目裡。** 文獻拼裝的 cargo 清單與同一批樣本實測的
> cargo 清單，是兩種完全不同的證據，能支撐的結論也不同（見 §2 L2-e）。

### 1.4 出題前先寫下三行判定標準

**如果你沒辦法在讀答案之前寫下這三行，這一題就還不能當測驗題** —— 因為之後不管它寫什麼，你都會覺得「有講到」。

```
這一題我期待的終局是：  PROCEED（給出實質分析） / HALT（正確答案是拒絕作答、說資料不足）
我會拿來做的決定是：    （例：決定下個月要不要花錢做 cargo 的 small-RNA-seq）
會讓我說「這答案不行」的是：（一句話，具體）
```

> **一批題目裡至少 1/3 應該是「正確答案是拒絕作答」的題。**
> 一套從不說「不」的系統，對任何東西都會生出一個陽性結果，等於沒有價值。

## 2. 收到答案後：10 分鐘驗證流程

四層，由淺入深。**L0 和 L1 不需要領域知識，任何人都能跑；L2 只有你做得到；L3 決定它值不值得再用一次。**

### L0 —— 三個 30 秒的致命檢查（先做這個，沒過就不用往下看）

| # | 動作 | 沒過長什麼樣 |
|---|---|---|
| 1 | **隨機抽 3 條引用，打開 PMID 讀摘要** | 看的是「摘要有沒有支持**那一句話**」，不是「有沒有這篇論文」。**真論文被拿來撐它沒說過的話，就是幻覺，等同造假。** |
| 2 | **隨機抽 3 個數字，回去對原始資料或原文** | 表格列數 ≠ 標題宣稱的數量；圖上的數字對不回原文 |
| 3 | **搜尋「未報導 / not reported」** | 一份橫跨數十篇文獻的表，如果**一個空格都沒有**，通常不是資料很完整，而是有人把洞補起來了 |

任何一項沒過 → **整份退回**，不要挑好的部分用。

### L1 —— 通用檢查（不需要領域知識，7 項）

| # | 看哪裡 | 出問題長什麼樣 |
|---|---|---|
| 1 | 開頭的結論 vs 最後的限制 | 開頭說「值得推進」、限制卻說「療效未證實」→ 自己跟自己打架 |
| 2 | 有沒有矛盾／衝突清單，而且**不是空的** | 空的通常代表方向性檢查壞掉。「每個標的都剛好有利」是循環論證 |
| 3 | 每個「未量測／方向未定」的主張，有沒有配 **assay + 讀出 + 判死條件** | 只留一句「方向未定」＝把該做的工作丟回給你 |
| 4 | 該說「做不到」的時候有沒有說 | 資料不足卻硬做出一個完整分析 |
| 5 | 途徑／暴露前後一致 | 外用製劑卻寫全身性收案族群、血漿親和力 |
| 6 | 數字有沒有附**量測條件** | 腸長度沒寫新鮮 vs 固定、有沒有張力 → 不可比（Q2 的表格特別要看這一欄） |
| 7 | 方法註腳（pipeline 版本 / session 編號 / 資料庫存取日期） | 沒有這一行，兩份結論相反的報告就只是「無法解釋的矛盾」 |

### L2 —— 領域專家檢查（只有你做得到，5 個動作）

這五個動作全部來自會議上孟青與彥安**實際做過**的判斷。它們是可以教、可以重複的「招式」，不是靈感。

#### (a) 相鄰模型檢查 —— 本次最大的失分點 ★

> **實例（Q2）：** 他們的模型是**皮膚特異性** Regnase-1 (Zc3h12a) KO，腸道並不缺失。
> 孟青指出：有一篇論文**直接在腸道**把同一個基因剔除，發現**大腸長度改變、小腸沒有**；
> 另一篇是**同家族另一個成員**的 KO（逐字稿聽寫，實際基因符號待孟青確認），含 colitis model，
> 也**記錄了**腸道長度，只是沒有特別著墨。**這兩篇 agent 都沒有找到。**
> 她的評語是關鍵：「我覺得這個很直觀，可是他沒有想到。」

這不是檢索能力不足，是**沒有展開該展開的搜尋軸**。它可以被列成清單、逐項檢查：

| 搜尋軸 | 問法 | 出現在答案裡？ |
|---|---|---|
| **同基因 · 不同組織** | 這個基因在**目標器官本身**被剔除時會怎樣？ | ☐ |
| **同家族 · 不同成員** | paralog／同家族成員的 KO 有沒有相同表型？ | ☐ |
| **同表型 · 不同基因** | 還有哪些基因會產生同一個表型？ | ☐ |
| **相反方向** | 過表現／回補會不會反轉？ | ☐ |
| **相鄰疾病模型** | colitis 等模型有沒有**順帶記錄**這個量測值（即使不是它的主題）？ | ☐ |

**修法（一句 prompt 就能補）：**
「在往下分析之前，先展開四條搜尋軸：同基因不同組織、同家族成員、同表型不同基因、相反方向擾動。
每條軸各列出你找到與沒找到的，包含**只把該數值當附帶記錄**的論文。」

#### (b) 分支窮盡檢查（MECE）★

> **實例（Q2）：** agent 給了一個 decision tree ——「如果腸子變長，接下來看 mucosa 有沒有變厚 / muscularis 有沒有變厚」。
> 孟青的實測結果是**兩個都變厚，而且 crypt 也有變化**，這一格不在樹上。
> Joseph 認為那是 AI 的侷限（沒有論文提到兩個都變厚）。

**這一點值得分清楚：它不是文獻覆蓋率的問題，是邏輯完整性的問題。**
決策樹的分支必須窮盡，這跟文獻有沒有報導過無關 —— A 變厚、B 變厚、**兩者都變厚、兩者都沒變**，
本來就該有四格。所以它是**可以要求、也可以逐格檢查**的：

> **檢查：** 任何 if/then 分支或決策樹，把所有組合列出來，看有沒有缺格（尤其是「both」與「neither」）。
> **修法：** 「你的決策樹必須窮盡所有組合（含 both / neither），
> 每一格都要寫出它各自代表的機轉解讀與下一步實驗。」

#### (c) 方法相依性檢查

答案有沒有**條件化在你揭露的方法上**？還是給了一個跟你的 protocol 無關的通論？

- 你說了用哪一種酵素 → 它有沒有講這個酵素會切掉／降解哪些表位，會不會打到你的 flow panel？
- 你說了是 spatial 不是 dissociation → 它有沒有換掉「細胞比例」類的結論？
- 你說了 RIN 值 → 它有沒有指出哪些結論在這個品質下不成立？
- **它有沒有在該追問的時候追問？**（Q1 它就做對了：先問「你要看 IEL 還是 LP，要不要含 muscle layer」）

#### (d) 隱性共識檢查 —— 它知不知道這行「大家沒寫出來的默契」

> **實例（Q1，這次答得最好的地方）：** 大部分人只講 intraepithelial 與 lamina propria 兩層，
> 直接忽略最下面的肌肉層；而**論文寫「LP」的時候其實通常包含肌肉層，很少有人特別把肌肉那一層撕掉**。
> agent 主動點出了這一層；在孟青回答「看 IEL 和 LP 就好」之後，
> **後續分析仍然標註了「這篇方法學宣稱是 LP，實際包含 muscle layer」**。孟青對這題的評價是「回答得還蠻不錯的」。

這是這類系統最有價值、也最難得的表現：**把定義的鬆散處攤開，而不是跟著大家含混過去。**
檢查方式很簡單 —— 挑一個你這行「大家都這樣寫但其實不精確」的名詞，看它有沒有拆開。
沒拆開＝它在複述文獻表面；拆開了＝它讀進了方法段。

#### (e) 輸入資料自洽性檢查（給拼裝資料用）★

> **實例（外泌體，彥安的問題）：** 「如果我丟進去的東西是兩個互為競爭的 non-coding RNA，
> 那這個東西會同時存在。同時存在是合理的嗎？……是不是應該被我們安全審查給審查掉，
> 還是這裡它有可能是合理的、我們不應該在這邊有太多的介入？」

**這個問題本身就是正確的用法。** 答案是：**agent 該做的是「標記並要求證據」，不是替你判斷生物學。**
三種可能，處理方式各不同：

| 可能性 | 判別依據 | agent 該做的 |
|---|---|---|
| **真的共存**（不同細胞來源、不同時間點、不同 EV 次族群） | EV 本身高度異質，一支製劑本來就是混合物 | 標記為「共存需以**同批、同方法**的量測佐證」 |
| **拼裝造成的假象**（兩個數字來自兩篇不同論文、不同細胞、不同平台） | 你的 cargo 清單是文獻拼的（§1.3） | **必須標記** —— 這是資料血緣問題，不是生物學問題 |
| **真的互斥**（同一批樣本、同一方法測到互相拮抗的兩者） | 需要原始資料 | 標記為待解衝突 + 指定判別實驗 |

孟青給的處理原則也很實際：「那就要去讀 paper 啊，就是去看說這兩個 long non-coding RNA
本身是應該同時存在還是不存在。」—— 也就是說：**衝突標記是 agent 的工作，衝突裁決是人的工作。**
你要驗收的是「它有沒有標」，不是「它判得對不對」。

> **一般規則：拼裝資料（來自多篇論文的 cargo／參數清單）進來時，每一列都必須帶著它的來源與量測方法。
> 做不到這件事的分析，結論的可信度上限就是「假設性」。**

### L3 —— 決策實用性檢查（三句話，決定它有沒有用）

會議上 Joseph 稱這個面向為「前瞻性」，孟青用一個非常具體的場景把它坐實了：

> 「今天覺得這個實驗很值得做……你就可以去申請資金。可是通常 reviewer，如果剛好是那方面的專家，
> 他可能會說『我這樣看，我大概就知道你們這個做出來的結果大概會是什麼』。
> 假設如果你有這個 agent 可以先跑，它可以很明確告訴你……那你就覺得 ok，所以這個其實是值得做的實驗，
> 因為如果你本來就可以很容易預測到它的結果，那做的那個意義就變小。」

所以 T3 的最終驗收就是三句話：

1. **星期一我要做什麼？** —— 有沒有指名**最便宜且具決定性**的那一個實驗（而且它真的最便宜、真的有決定性）？
2. **什麼結果會讓這個想法直接死掉？** —— 有沒有寫出判死條件？
3. **這個實驗還值不值得做？** —— 它的結果是不是**已經可以預測**？
   如果 agent 讀完文獻後能高信心地告訴你結果會是什麼，這個實驗的新穎性就低（可以省下錢）；
   如果它讀完後仍然給出**具體而互斥的幾種可能**，那就是值得做的實驗。

**三句話都答不上來的答案，寫得再漂亮也是零分。**

## 3. 三型題目的計分卡（可直接列印使用）

### 3.1 T1 記分表 —— 你手上有答案時

事前把答案原子化：**一句話 = 一個可否證的事實**，每個事實附 PMID 與出處位置（Abstract／Results／Fig. 2）。
出處位置要記，因為**數字只在圖裡而 agent 抓不到全文，是覆蓋率問題，不是捏造問題**，兩者分開計分。

| 判定 | 意思 | 權重 |
|---|---|---|
| **HIT** | 有寫、正確、引用也對 | **+1** |
| **MISS** | 沒提到 | **−1** |
| **CONTRADICTION** | 有寫但寫錯 | **−10** |
| **UNSUPPORTED** | 有寫，但引用的文獻並不支持這句話 | **−10** |

- **命中率 Recall** = HIT /（HIT + MISS）
- **捏造率** =（CONTRADICTION + UNSUPPORTED）/ 每 100 條主張 → **這是頭號數字，門檻是 0**
- **★ 陷阱題（抓捏造最有效的一招）：** 刻意放 2–3 個「文獻上根本沒人量過」的欄位，正確答案是**「未報導」**。
  會照實寫「未報導」的系統，跟會補一個看起來合理的數字的系統，只有這種題分得出來。
- **絕對不要只公布 recall。** 只要開始優化 recall，系統就會把清單放寬、什麼都寫進去。
  **每一個 recall 都必須配一個捏造率。**

### 3.2 T2 預先登錄書 —— 實驗還在跑時

**揭盲前寫完並註明日期；沒有事前登錄的預測不計分。**

```
預測：      （例：小腸長度差異的主要驅動層 = 外縱走肌）
數值區間：  （例：+5~10 cm，新鮮組織、固定張力）
方向：      （增長 / 縮短 / 無差異）
判讀方式：  （分層形態計量：mucosa／submucosa／inner circular／outer longitudinal／crypt／villus）
★ 量測 SOP：（工具、放大倍率、每隻取樣切片數、每張切片量測條數、由誰量、盲不盲）
★ 量測誤差：（同一張切片重複量的變異；低於這個變異的差異一律視為無差異）
判死條件：  （例：若增長主要來自 mucosa 而肌層厚度無差異 → 本假說否證）
登錄日期：
```

> **★ 為什麼多了量測 SOP 這兩行。** 會議後半在討論用 ImageJ／QuPath 自動量絨毛長度與黏膜厚度，
> 結論是：傳統 edge detection **只抓得到比較直的絨毛**，彎曲的還是得靠人看。
> 這代表**讀出值本身帶著方法相依的誤差** —— 不先把量法與誤差釘死，
> 事後你沒辦法判斷「預測落在區間內」到底是命中，還是量測噪音。
> **預先登錄的預測，必須配一份預先登錄的量法。**

計分：方向命中／未中 · 區間覆蓋（真值有沒有落在宣稱區間內）。
**要公布失準** —— 一次有預先登錄的失準，價值高於十次事後諸葛的命中。

### 3.3 T3 量表 —— 沒有答案時（五面向，各 0–3 分）

| 面向 | 問題 | 0 分 | 3 分 |
|---|---|---|---|
| **可追溯性** | 每個數字能不能回到來源？ | 有數字沒出處 | 每個頭條數字都能一路走回原始資料 |
| **可否證性** | 未量測的主張有沒有配 assay + 讀出 + 判死條件？ | 只寫「有待驗證」 | 每一條都有具名實驗與判死線 |
| **安全性覆蓋** | 該 modality 的危害有沒有被處理？ | 完全沒提 | 有處理且配了具名實驗 |
| **內部一致性** | 結論／表格／限制三者不打架？衝突清單非空？ | 開頭與限制矛盾 | 一致，且主動列出矛盾 |
| **決策實用性** | §2 L3 那三句話答得出來嗎？ | 答不出來 | 指名最便宜且具決定性的實驗 |

**★ 兩個把「沒有標準答案的題目」變成可打分的技巧：**

1. **隱藏檢查點** —— 出題前先寫下 2–3 個「你已經知道應該被提到」的風險，
   例如外泌體製劑的**內毒素／無菌性／黴漿菌／免疫原性／致瘤性 cargo／促血管新生 cargo／批次鑑定（MISEV）**，
   或外用製劑的接觸性致敏。報告沒提到 → 覆蓋率扣分。
2. **反駁任務** —— 另外開一個**獨立**的對話，任務是**駁倒**這份報告的前三大主張，看幾條活得下來。
   **絕不可以讓寫報告的那個 session 自己打分。**

> **注意（目前的已知弱點）：** 系統實測顯示，安全性只有在「生物學剛好逼出來」時才會出現 ——
> 三次外泌體 run 沒有任何一次處理到 EV 的產品品質類危害（無菌性／內毒素／免疫原性／致瘤性）。
> **所以安全性這一項請你務必手動檢查，不要假設它跑過了。**

## 4. 最容易吵架的地方：「可接受的限制」vs「不可接受的失效」

會議上出現過一次很典型的分歧 —— decision tree 少了「兩個都變厚」那一格，
Joseph 說「這也是 AI 的侷限性，因為沒有 paper 提到」，孟青說「但我覺得這樣也是好的」。
**兩人講的其實不是同一件事**，把它們分開，之後就不用再爭論：

| 類別 | 長什麼樣 | 會議中的實例 | 判定 | 怎麼修 |
|---|---|---|---|---|
| **A. 覆蓋率缺口** | 文獻上就沒有，或數字只在圖裡抓不到 | 沒有論文報導「mucosa 與 muscularis 同時增厚」 | **可接受**，但**必須標示為「未報導」** | 無需修；這正是你的實驗的價值所在 |
| **B. 推理缺口** | 資料有、邏輯沒展開 | 決策樹分支不窮盡（缺 both／neither） | **扣分，但非致命** | 一句 prompt 要求窮盡分支（L2-b） |
| **C. 檢索軸缺口** | 該找的方向沒去找 | 沒找到腸道特異性 KO 與同家族成員那兩篇 | **扣分，且是最值得回報的一類** | 展開四條搜尋軸（L2-a） |
| **D. 方法脫節** | 沒有條件化在你的 protocol 上 | 給細胞比例結論卻不管你用哪種酵素 | **扣分** | 補方法揭露區塊（§1.2） |
| **E. 捏造** | 編數字、真論文撐它沒說過的話 | —（本次未發現，但這是頭號監控項） | **致命，整份退回** | 不可修，只能重跑並記錄 |

**這張表的用法：** 回報問題時，先標上 A–E 的代號。
標 A 的不用改系統（要改的是你的期待）；標 B/C/D 的通常一句 prompt 就能補，而且**應該進題庫變成常駐迴歸題**；
標 E 的要立刻停下來查。

## 5. 常見情境的處方

| 情境 | 怎麼做 |
|---|---|
| **「我拿不到廠商的 CMC／方法資料」** | 不要讓它假設。改問：缺這些資料，**哪些結論現在就不成立**？並要一份**按影響排序的最小索取清單**（RIN、分離法、批次、MISEV 鑑定項目）。 |
| **「兩個互相競爭的分子同時出現，該不該擋？」** | agent 負責**標記**，你負責**裁決**（L2-e）。驗收的是「有沒有標記並要求同批同法的證據」，不是它判得對不對。 |
| **「這個領域我不熟，沒辦法判斷內容」** | 只跑 **L0 + L1 + 反駁任務**。這三項不需要領域知識，而且抓得到最致命的那一類問題。 |
| **「同一題問兩次，答案不一樣」** | 這叫穩定性，不是錯誤。**記下分歧的具體內容**（哪個基因／哪個結論掉了）並回報，然後**不要重問到滿意為止** —— 那只是在挑選你喜歡的答案。 |
| **「它的答案讀起來很有道理」** | 「讀起來有道理」不是證據。跑 L0 第 1 項（抽引用讀摘要）—— 這是所有檢查裡投資報酬率最高的 30 秒。 |
| **「它反過來問我要不要指定某個條件」** | **這是好現象**（Q1 它問了 IEL / LP / muscle layer）。回答它，並把你的回答一起存進題目 —— 下次重跑要用同一份，否則兩次不可比。 |

## 6. 回報格式 —— 一張卡，讓你的判斷變成可累積的資產

```yaml

預期終局:       PROCEED
要做的決定:     決定是否投入分層形態計量

L0 致命檢查:    引用抽驗 3/3 通過 · 數字抽驗 3/3 通過 · 有寫「未報導」 ✔
發現的問題:
  - 代號: C        # A覆蓋率 / B推理 / C檢索軸 / D方法脫節 / E捏造
    描述: 未找到腸道特異性同基因 KO（大腸有變化、小腸無）與同家族成員 KO（含 colitis model）兩篇
    影響: 缺少最直接的對照模型，機轉解讀少了一個分岔
  - 代號: B
    描述: 決策樹缺「mucosa 與 muscularis 同時增厚」分支；實測兩者皆增厚且 crypt 有變化
    影響: 實測結果落在樹外，無法接續判讀
答得好的地方:
  - 主動追問要看 IEL / LP / 是否含 muscle layer，且後續標註「論文稱 LP 通常包含 muscle layer」
決策實用性:     2/3   # 有下一步實驗，但未指名最便宜且具決定性的那一個
結論:           FIX-FIRST   # SHIP 可用 / FIX-FIRST 修完可用 / BLOCK 退回重做
```
